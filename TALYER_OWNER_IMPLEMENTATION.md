## 🔧 Technical Implementation

### Database Integration
All data is fetched directly from Supabase tables:
- `shops` - Shop information
- `service_providers` - Mechanic data
- `mechanic_job_history` - Job records and earnings
- `invoices` - Invoice data
- `service_requests` - Service request information
- `request_status_history` - Status change timeline
- `mechanic_availability_status` - Real-time availability

### API Service Methods

#### Dashboard
- `getShopId()` - Get shop ID for current owner
- `getDashboardOverview(shopId)` - Fetch all dashboard metrics

#### Invoices
- `getInvoices()` - List invoices with filters
- `generateInvoiceCSV()` - Export to CSV

#### Mechanics
- `getMechanicsPerformance(shopId)` - Get all mechanic stats

#### Reports
- `getRevenueReport()` - Generate revenue analytics

#### Service Requests
- `getServiceRequests()` - List requests with filters
- `getRequestStatusHistory(requestId)` - Get status timeline

#### Settings
- `getShopSettings(shopId)` - Load current settings
- `updateShopSettings()` - Save configuration changes

### Real-Time Subscriptions
```dart
subscribeToDashboardUpdates(shopId, callback)
```
Monitors changes to:
- Service requests
- Invoices
- Job history

## 📝 Notes

### Export Functionality
The CSV export in `invoice_management_screen.dart` requires the `share_plus` package. If not installed, you can:
1. Add to `pubspec.yaml`: `share_plus: ^7.0.0`
2. Run: `flutter pub get`
3. Or remove the export feature if not needed

### Database Queries
All queries use proper error handling and null safety. Make sure your Supabase RLS policies allow shop owners to access their own data.

### Real-Time Updates
Real-time subscriptions are automatically cleaned up when screens are disposed. No manual cleanup needed.

## 🐛 Troubleshooting

### Common Issues

**Error: Shop not found**
- Ensure user is logged in as shop owner
- Verify shop record exists in database
- Check `owner_id` matches authenticated user

**Data not loading**
- Check internet connection
- Verify Supabase configuration
- Check RLS policies on tables
- Ensure API key is valid

**Real-time updates not working**
- Verify Supabase real-time is enabled
- Check channel subscriptions
- Ensure proper permissions
