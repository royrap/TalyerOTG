## 📋 Check the Database

### **Option 1: Check if QR code exists for this job**

Run this in your **Supabase SQL Editor**:

```sql
-- Check if job completion code exists
SELECT 
  jcc.completion_code,
  jcc.is_used,
  jcc.expires_at,
  jcc.created_at,
  sr.id as service_request_id,
  sr.status as job_status
FROM job_completion_codes jcc
JOIN service_requests sr ON sr.id = jcc.request_id
WHERE sr.id = 'ef7c9c11-d91e-449a-902a-c78b1f3a313e';
```

**Expected Result**:
- If row exists: You'll see the actual `completion_code` (e.g., "BPOQYAUC-3899" or similar)
- If no rows: QR code hasn't been generated yet

## 📱 Customer QR Code Generation Flow

**File**: `lib/services/qr_code_service.dart`

The customer's QR code is generated by:
```dart
Future<String?> showCustomerQRCode(String serviceRequestId) async {
  // Checks if code already exists
  final existingQR = await _supabase
      .from('job_completion_codes')
      .select('completion_code, expires_at')
      .eq('request_id', serviceRequestId)
      .eq('is_used', false)
      .maybeSingle();

  if (existingQR != null) {
    return existingQR['completion_code'];  // Returns existing code
  }

  // Generate new if doesn't exist
  return await generateJobCompletionQR(serviceRequestId);
}
```

**Trigger Points**:
1. When customer navigates to `JobCompletionQRScreen`
2. After payment is completed
3. From invoice screen "Show QR" button

4. **Mechanic scans QR** → Camera or manual entry
5. **System validates code** → Checks database
6. **Job marked complete** → Both tables updated
